1. Configurar o Git
git config --global user.name "Luiz-gp"
git config --global user.email "luiz.pereiragus@gmail.com"

2. Inicializar o Git
git init 

3. Criar o repo no GitHub
Nome do repo: Aula1

4. Nesta etapa, é a etapa de desenvolvimento ou seja, alterações nos nossos arquivos. Site, projetos, arquivos, texto, entre outros.

5. Após a conclusão do desenvolvimento, adicionar os arquivos ao repo:
git add .


REPETIR PASSO 5 , 6 e 7 SEMPRE QUE HOUVER ALTERAÇÃO NOS ARQUIVOS DO PROJETO.


6. Comitar ao repositório com uma mensagem explicativa: git commit -m "Mensagem entre "" "

7. Associar ao nosso repo local com o remoto
git remote add origin LINK_DO_REPO
git branch -M main
git push -u origin main
